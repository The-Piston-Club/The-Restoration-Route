# The Restoration Route — scale/layout corrected build

Open `index.html` locally or upload the folder to GitHub Pages.

## What changed in this version

- The workshop background is displayed without cropping the top off, and the part coordinates now match the full generated background image.
- Home-screen part overlays no longer have title labels, status circles, or X icons.
- Each part appears once on the workshop floor: damaged first, repaired after the QR/code is claimed.
- The parts are spaced into their own clear areas on the floor.
- The part sizes have been rebuilt so the wheel/tyre is largest, spark plugs are much smaller, and everything else sits between them.
- The component PNGs have been re-cut from the supplied green-screen image, fixing the bad brake-pad crop from the first version.
- Venue pages now sit directly over the service-book background rather than in obvious boxed cards.

## Test codes / QR URLs

Use any of these query strings to simulate a venue QR:

- `?venue=engine`
- `?venue=fuel-system`
- `?venue=bodywork`
- `?venue=chassis`
- `?venue=lubrication`
- `?venue=cooling`
- `?venue=transmission`
- `?venue=tyres`

The menu button can also copy the full QR link list for generating printed QR codes.
